In the Jenkins CI, I'd like to enhance the information posted to github. I'd like all the warnings and any errors to get posted in the github log. There should always be a log posted to github, even in the case of failure, with detailed feedback about why the build failed, and any warnings that were posted. It would be helpful to do a diff between the branch being examined and main, so that we can understand if this branch is introducing any warnings. Therefore, some kind of "new warnings" section would be helpful. Putting the errors and warnings in a drop-down bar would make it nice to look at, contained and organized
