Gkeyll now has a Jenkins-based CI system in ci/jenkins. The CLI for it uses ci/jenkins/gkeyll-ci.sh, see

ci/jenkins/gkeyll-ci.sh -h

This is fine, but the help menu doesn't describe the possible flags for each command. It'd be good if one could do

ci/jenkins/gkeyll-ci.sh run -h

and see the flags available for use with the run command. To do this, I think we should change the underlying scripts (for personal, stellar, perlmutter, team machines) so that:
1) ./ci/jenkins/jenkins-personal.sh -h provides a list of commands without flags
2) ./ci/jenkins/jenkins-personal.sh run -h provides a sub-menu with options for the run command.

This way gkeyll-ci.sh remains a thin wrapper for the other scripts.
